# Parcel App Template

Basic structure for a website/webapp with Parcel.js

## Features
* Styled components
* Dark mode
* Bundling
* Offline functionality

## Styled components

### Content

```html
<h1>Large heading</h1>
,
<h2>Medium heading</h2>
,
<h3>Small heading</h3>
<a href="#">Hyperlink</a>
<code>Monospace</code>, <strong>Bold</strong>, <em>Italic</em>,
<u>Underline</u>, <s>Strike-through</s>

<ol><li>Ordered list</li></ol>
<ul><li>Unordered list</li></ul>
```

### Buttons

```html
<button class="btn">Primary button</button>
<button class="btn sec">Secondary button</button>
```

### Forms

```html
<input type="text" placeholder="Text field" class="field" />
<textarea placeholder="Dynamic textarea" class="field autogrow"></textarea>

<input type="checkbox" id="checkmark" class="checkmark" />
<label for="checkmark">Label for checkmark</label>

<input type="switch" id="y" class="switch" />
<label for="switch">Label for switch</label>

<input type="radio" name="select" id="yes" class="radio" />
<label for="yes">Yes</label>
<input type="radio" name="select" id="no" class="radio" />
<label for="no">No</label>
```

## Start Dev Server

`npm run start`

## Build Project

`npm run build`
